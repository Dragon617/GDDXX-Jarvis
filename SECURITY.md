# Security Policy

## Supported versions

Security fixes are applied to the latest release of GDDXX-Jarvis.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue. Use GitHub's **Security** tab and select **Report a vulnerability** to send a private report to the repository owner.

Include the affected version, Windows version, reproduction steps, impact, and any suggested mitigation. Remove API keys, personal data, conversation content, and local file paths from screenshots and logs.

The project will acknowledge a complete report as soon as practical, investigate it, and coordinate disclosure after a fix is available. Never include real credentials in a test case.
